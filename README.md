# ADR (Active Debris Removal) ゲーム

衛星事業者として、衛星への投資、宇宙デブリ除去、減価するADR通貨の売買・利用を体験するシリアスゲームです。個社の利益と軌道環境の改善を両立できるか、除去費用を市場と社会に分散できるかを観察します。

ゲーム設計は **Shinji Hatta**。このリポジトリでは、**v1.0** のゲームをAIがゲームマスター（GM）として進行するための指示とドキュメントを提供しています。プレイヤーの言語に合わせて日本語・英語などで遊べます。コントリビューターと関連論文は [AUTHORS](AUTHORS) を参照してください。

遊び方の詳細は [ゲームルール](docs/game-rules.md)、背景となる制度仮説は [制度の考え方](docs/concept.md) で説明しています。

## シングルユーザーで遊ぶ

[loglm](https://github.com/ks91/loglm) と利用するコーディングエージェントを準備し、ゲーム用の作業ディレクトリで実行します。

```sh
loglm agent install ks91/adr-game
```

ローカルにあるリポジトリからインストールする場合は、そのパスを指定します。

```sh
loglm agent install /path/to/adr-game
```

起動したエージェントへ「ADRゲームを始めよう。日本語で、私1人とNPCで遊びたい」と伝えます。初期資産、NPCの人数・方針、終了条件、未確定事項の扱いを確認したら開始です。1人で全社を操作したい場合は、その担当も指定できます。

配布元は [AGENT_INSTALL.md](AGENT_INSTALL.md)。会計・乱数には実行環境を使い、状態はローカルに保存します。計算環境が使えない場合は開始前に案内されます。

## Discordでみんなで遊ぶ

[discord-agent-hub](https://github.com/ks91/discord-agent-hub) を設定済みのサーバーで利用します。

1. [sg-adr-game.md](sg-adr-game.md) を `/agent-import` に添付して取り込みます。更新時は `overwrite:true` を指定します。
2. `/chat agent_id:sg-adr-game` でゲーム用スレッドを作ります。
3. 参加者がスレッドで参加を表明し、各自の会社、進行役、NPC、初期設定と終了条件を確認します。NPCの個別行動はGMが自動で決めます。
4. 毎ターン、各自が自社の行動を宣言します。全員の入力が揃ってから処理します。

1スレッドが1ゲームです。`gpt-5.6-luna` での実プレイによる動作確認が行われており、標準モデルとして設定しています。コード実行は有効、Web検索は無効です。APIとコード実行の費用が発生します。

状態はGMが会話内に記録し、計算環境がリセットされても会話から復元します。毎ターンのJSON保存・再アップロードは不要です。別スレッドへの移動などで必要なら「セーブファイルを出して」と頼めます。

Discordの状態表は画像＋短いテキスト要約を標準とし、「テキスト表示にして」「Markdown表にして」でいつでも切り替えられます。読み上げ向けテキストは項目名付きの一覧です。画像生成に失敗してもテキストで進行します。NPCは標準では収益・資金余力・除去投資のバランスを考えて自動行動し、方針変更を希望するときだけ指示します。

## プレイヤーがすること

全員が衛星事業者です。通信衛星とデブリ除去衛星を自由に組み合わせます。

| 選択・処理 | 標準設定 |
| --- | --- |
| 通信衛星購入 | 1機10 Cashまたは10 ADR。翌ターンから毎ターン3 Cashの収益 |
| 除去衛星購入 | 1機20 Cash。生涯5試行、1ターン1試行 |
| デブリ除去 | 成功80%、無事失敗15%、自機デブリ化5%。表示された候補から選択 |
| ADR売買 | 1 ADR = 1 Cash。除去報酬の売却は翌ターン以降。購入は市場残存量以内 |
| ADR減価 | 会社保有分5%、市場保有分2%。市場残高の別途3%相当は社会負担として記録 |
| 税・留保負担 | 課税所得の20%を法人税として控除後、正のCash残高の2%を控除 |

行動例: 「通信衛星を1機Cashで購入」「R-C-001でD022を除去」「ADRを5売却」「何もしない」。

GMが状態と候補を示し、収益反映、行動入力、購入・除去・ADR売買、事故、減価、税、Cash留保負担の順で進めます。ルールにない支払い・効果や未確定事項は合意してから使います。子供向け表示でも計算は変わりません。

## ドキュメントと開発

- [AUTHORS](AUTHORS): コントリビューターとGALA 2025発表論文。
- [ゲームルール](docs/game-rules.md): 初期設定、衛星、除去、ADR、事故、税と減価、ターン進行。
- [制度の考え方](docs/concept.md): 除去報酬、通貨循環、社会分散負担、制度の観察項目。
- [運用方針と合意事項](docs/rule-decisions.md): 計算規則の解釈、開始時に決める事項、環境ごとの進行方法。
- [プレイ検証](docs/playtest.md): 会計の期待値とシングル／マルチユーザーの確認手順。
- [旧v0.1](docs/history/v0.1.md): GALAConf 2025発表版。現行ルールとは混ぜません。

共通本文は `prompts/core.md`、環境別指示は `prompts/single-player.md` と `prompts/multi-player.md` です。配布する2ファイルはそれぞれ単独で利用でき、外部のルールファイルを読み込む必要はありません。編集後はPython 3（標準ライブラリのみ）で再生成します。

ルール改訂時は日本語文書と共通本文の内容も照合します。

```sh
python3 scripts/build_prompts.py
python3 scripts/build_prompts.py --check
```

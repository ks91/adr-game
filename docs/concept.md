# ADR通貨制度の考え方

Shinji Hattaが設計したADR通貨シリアスゲームv1.0の背景にある制度仮説と、プレイを通じて観察する論点を説明します。実際のプレイの計算は [ゲームルール](game-rules.md) を参照してください。

## なぜ除去報酬を通貨で与えるのか

デブリ除去による軌道環境の改善は宇宙利用者全体に利益をもたらします。しかし、その利益を除去した会社だけが収益として回収できるとは限りません。除去費用や失敗リスクを誰が負担するかが、このゲームの出発点です。

ADR通貨は、除去成功を通貨発行の起点にする制度仮説です。除去した会社は報酬としてADRを得て、売却や宇宙関連支払いに利用します。ADRが市場へ移り、再利用され、減価する過程を通じて、費用負担を時間的・社会的に分散できるかを検討します。

これは制度設計を試すゲーム上のモデルです。現実の税制や会計・金融制度をそのまま再現したものではなく、制度が持続可能になることをあらかじめ結論づけるものでもありません。

## 発行・循環・減価

除去成功時にだけADRを発行します。会社がADRを売却すると市場へ移り、他の会社がCashで買い戻すか、支払いに使うことで循環します。CashからADRへの交換は市場に実在するADRの範囲内で行い、交換に応じて新規発行はしません。

マーケットは単一の銀行ではありません。金融機関、決済会社、衛星メーカー、保険・安全サービス、宇宙サービス利用者、政府などを抽象化した経済圏です。社会への負担分散は、料金や価格への転嫁、決済費用、政策的な負担等を広く薄く引き受ける状況を表現します。ゲーム内では各主体の個別会計までは再現しません。

## v1.0の負担の分け方

| 保有場所・資産 | 実際に減る残高 | その他の記録 |
| --- | --- | --- |
| 会社のADR | 毎ターン5% | 保有会社自身の資産減少 |
| 市場のADR | 毎ターン2% | 減価前残高の3%相当を社会分散負担として記録 |
| 会社のCash | 法人税後の正の残高の2% | Cash留保負担として記録 |

市場ADRの名目減価率は5%ですが、その損失の60%を社会が吸収すると仮定します。そのため、実際に消えるADRは `5% * 40% = 2%`、社会分散負担は `5% * 60% = 3%` 相当です。

ここでは「ADRがどこで減ったか」と「その価値の損失を誰が負担したとみなすか」を分けています。社会分散負担を会社のCashへ再請求せず、同額のADRを追加発行もしません。旧版の、ADR減価額の一部を会社のCash比で配賦する方式は採用しません。

## プレイヤーに生じる選択

除去会社は、除去衛星の購入費、限られた試行回数、失敗や自機デブリ化のリスクと、獲得できるADRを比較します。高価値のデブリが減った後にも事業が続くかが重要です。

通信衛星を持つ会社は、収益をCashとして留保するか、通信衛星や除去衛星へ再投資するか、ADRを購入・使用するかを選びます。除去への投資は他社にも事故率低下の利益をもたらします。兼業なら通信衛星の収益で除去投資を支える選択もできます。

ADRには5%の減価があり、Cashには2%の留保負担があります。CashをADRへ替えるだけで有利になるとは限りません。Cash留保負担の目的はCash保有の禁止ではなく、保有と支払い・投資との比較に小さな費用を置くことです。

## 環境税との比較と観察項目

原案で比較対象とする環境税型モデルでは、除去費用を主に衛星事業者が直接負担します。ADR型では、除去への報酬を通貨として発行し、その後の保有・流通・減価を通じた分散を試します。この比較はゲーム上の制度仮説であり、あらゆる現実の環境税の性質を断定するものではありません。

プレイでは次を観察します。

- 除去会社は衛星投資を回収し、高価値デブリの枯渇後も事業を続けられるか。
- ADRは売却されるばかりでなく、買い戻しや支払いに使われるか。市場残高が増え続けないか。
- 残存デブリと事故率は下がるか。個社の利益追求と軌道安全は両立するか。
- 実際のADR消滅と社会分散負担はどれほど累積するか。特定の会社や事業構成へ依存しないか。
- 税・減価・Cash留保負担が資金移動にどう作用するか。兼業と専業の判断はどう変わるか。

減価率5%、市場実効2%、社会負担3%、Cash留保負担2%は検証対象のパラメータです。ADR需要を生むサービス、市場価格、課税対象、社会負担の現実的な仕組みへの対応も今後の検討事項です。変更を試す場合は標準ゲームと区別して設定を記録し、同じものを比較できるようにします。
